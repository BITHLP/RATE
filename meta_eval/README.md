# Meta-Evaluation

We utilize the [MT-Metrics-Eval (MTME)](https://github.com/google-research/mt-metrics-eval) toolkit to conduct meta-evaluation. Please ensure it is installed

## 1. Download Dataset
Download the **MENT** (<u>M</u>eta-<u>E</u>valuation dataset of <u>N</u>on-Literal <u>T</u>ranslation) dataset from [![HuggingFace](https://img.shields.io/badge/HuggingFace-MENT-ffd700?logo=huggingface&logoColor=yellow)](https://huggingface.co/datasets/yztian/MENT).

## 2. Format Conversion
Run `extract_meta_eval_data.py` to convert the MENT.jsonl into MTME-compatible format data in workspace.

## 3. Parse RATE Results
Run `RATE/parse_rate.py` to extract numerical scores (segment-level and system-level) from the raw evaluation trajectories generated by RATE.

## 4. Run Meta-Evaluation
Calculate the correlation using `metaeval.py`.
